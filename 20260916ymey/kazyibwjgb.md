# 「科普」中风后康复，别只盯着手脚——警惕“心灵伤口”：脑卒中后抑郁

> 更新时间：2026-09-16 (UTC+8)

近期，神经内科一病区李阿姨中风恢复后，家人发现她变了——曾经爱打麻将的她整日坐在窗前发呆，拒绝邻居邀约，常念叨“拖累你们”，深夜偷偷流泪。明明体检正常，她却总说头痛、没胃口、睡不着。医生评估后给出诊断：脑卒中后抑郁。

那么什么是脑卒中后抑郁？如何区别脑卒中后抑郁？如何进行治疗？下面我们一起来了解下。

脑中风后，当患者和家属正全力投入肢体或语言康复时，一种隐蔽却高发的障碍——脑卒中后抑郁常被忽略。它不是“矫情”或“意志薄弱”，而是脑卒中后常见的并发症，脑卒中后抑郁是指发生于卒中后，表现出卒中症状外的一系列以情绪低落、兴趣缺失为主要特征的情感障碍综合征，常伴有躯体症状。

**作为家属如何区别卒中抑郁呢？**
以下几点需要家属关注：

1. 患者情绪低落，大部分时间内总是感到不开心、闷闷不乐，甚至痛苦；

2. 丧失兴趣也是常见症状，对所有的爱好、工作及生活都不能从中获得愉悦；易疲劳，很多基本生活所需都力不从心，经常觉得生活没有意义，活着过于痛苦，严重者有自杀的倾向；

3. 躯体化症状较多，生理症状如体重减轻、入睡困难、眠浅多梦、 易惊醒和早醒、不明原因疼痛、食欲减退或亢进、性欲减退等；

4. 病人往往过分贬低自己的能力，以批判、消极和否定的态度看待自己的现在、过去和将来，这也不行，那也不行，把自己说得一无是处，前途一片黑暗。强烈的自责、内疚、无用感、无价值感、无助感，严重时可出现自罪、疑病观念。

**卒中后抑郁的病人如何摆脱抑郁？**
需要来自家庭及医院的联合治疗：

1. 对于脑卒中后抑郁病人来说，其常见的情绪有：恐惧、悲观、焦虑等，医护人员可对患者及家属开展疾病宣教，让患者了解自己的情绪是基于疾病出现的，只要积极配合治疗，科学用药，通常恢复情况都是很好的，从而缓解其心理压力，建立治疗和康复的信心。 

2. 家庭成员一定要给予患者更多的关心，给予生活上的照顾，鼓励患者力所能及地参加社会活动，要关注患者生病后的精神状态，做到早发现早治疗，避免说教和埋怨，更不要忽视患者的情感体验。朋友更要积极鼓励患者，在探望的过程中，不要说消极的话语，比如“会留后遗症”等，要给患者信心。

3. 积极治疗原发病，医生帮助患者肢体功能康复，患者配合医生康复锻炼。同时也要积极治疗抑郁症，达成一个良性循环。

**重要提示**

脑卒中后抑郁是大脑损伤后常见的并发症，不是患者的错，更非软弱！如同身体需要复健，心灵同样需要关爱与专业疗愈。及早识别、科学治疗、家人社会的温暖支持，是驱散阴霾、重燃康复希望的关键。 别让这场“心灵感冒”偷走宝贵的康复时机和生活的色彩。
