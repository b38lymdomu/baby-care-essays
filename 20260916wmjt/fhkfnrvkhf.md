# 百菜不如白菜！这样搭配，功效翻倍，补肾、防癌、降压、通便……

> 更新时间：2026-09-16 (UTC+8)

俗话说“百菜不如白菜”，现如今正是白菜刚上市的时候，不妨常吃。中医认为白菜微寒味甘，有养胃生津、除烦解渴、利尿通便、清热解毒之功。

不过白菜还分大白菜、小白菜、娃娃菜，不同品种效果不同：

**1**
**大白菜、小白菜、娃娃菜区别大**

1**小白菜——强筋壮骨**
小白菜中富含钙质，其钙含量为**70~100mg/100g**，可以**强筋壮骨**。小白菜还是蔬菜中**含锌量的冠军**，锌对于刺激食欲、促进钙的吸收都有帮助。

**一杯白菜汁中的钙含量几乎等于一杯牛奶的钙含量**，而且还更易吸收利用。

而且小白菜在白菜中颜色最绿，含的**叶绿素也最多**，能对抗自由基，有助于抗衰老。

2**娃娃菜——辅助****降压**
娃娃菜颜色偏黄，富含**钾元素**，能抑制钠的吸收，**有助于降血压**；

而且钾元素还是**维持神经肌肉应激性和正常功能**的重要元素，经常有倦怠感的人常吃些娃娃菜有不错的调节作用。

3**大白菜——辅助防癌**
大白菜里富含一种叫做**吲哚-3-甲醇**的物质，能促进人体产生一种酶，**抑制癌细胞的生长和扩散**；

富含的**钼元素**，能**阻断亚硝胺等致癌物质**在人体内的生成；含有的**维生素C**也能**抑制癌细胞繁殖**，达到预防癌症的目的。

**2**
**白菜这样搭配，功效翻倍**

1**白菜+蜂蜜，润肠**
**【做法】**

白菜洗净取白菜帮（白菜叶可去可不去），用家用榨汁机榨成30ml的白菜汁，兑上少许蜂蜜即可。可以起到**清热、润肠、通便**的作用。

2**白菜+板栗，健脾补肾**
中医认为，板栗具有**养胃、健脾、补肾、强筋**等功效。**维C**比西红柿高，**钾**的含量又是苹果的4倍，可以说是食补极佳的食材。而且板栗和白菜正当季。

**丁栗子扒白菜**
**【食材**】

白菜 / 栗子 / 葱姜 / 淀粉 / 油盐 / 鸡汤 / 白糖 / 鸡粉 / 鸡油

**【做法**】

**①焯煮白菜**：在锅内放入水、少许盐、白糖，烧开，手撕白菜叶焯煮至软扒成熟即可捞出。

（焯煮的好处：1杀菌消毒；2、去除苦涩味。）

**②煸炒**：锅上火，倒入少许油，爆香葱姜米。

**③调味**：依次放入鸡汁、煮熟的栗子、盐、白糖、鸡粉，拌匀后放入白菜烧煮。

**④勾芡完成**：烧透煮烂后放入少许水淀粉勾芡，晃锅至均匀，最后顺着锅边淋入少许鸡油拌匀即可出锅，完成~
