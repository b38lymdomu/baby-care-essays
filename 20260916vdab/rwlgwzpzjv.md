# 广东省生殖医院精液分析质量控制成果在国际男科顶级杂志公开发表

> 更新时间：2026-09-16 (UTC+8)

随着辅助生殖业界对男性生育力评估在不育临床诊疗的重要性的认识不断加强，规范准确实施精液分析成为众多从事男性生育力评估实验室的目标。精液分析质量控制是确保实验室检测结果准确的质量保证。

广东省生殖医院男科副研究员王奇玲为第一作者，男科主任张欣宗为通讯作者的论文“Evaluating an external quality assurance program for semen analysis in China during 2009–2020”， 在国际男科顶级杂志Andrology（影响因子4.674）免费公开发表。

广东省生殖医院男科团队率先在国内连续开展12年的精液分析质量控制实践，已成为目前国内生殖男科领域规模最大的精液分析外部质量控制体系，参与实验室超过180家。

该论文对广东省生殖医院12年来的精液分析外部质量控制实践进行总结分析，论述了精液分析在我国的开展现况及实际情况。论文指出，精液分析实践结果表明实验室精液分析结果差异性较大，尤其精子形态学和精子浓度的评估，各实验室精液分析结果的准确度仍需进一步提高，精液分析质量控制实践和规范培训非常有必要定期开展。

该论文首次展示了WHO精液分析手册（第五版）推出以来我国大规模精液分析外部质量控制实践成果，在精液分析质量控制研究领域发出了中国声音，也丰富了世界范围内精液分析质量控制的研究成果。

**广东省生殖医院**

**精液分析质量控制发展史**

广东省生殖医院男科集临床、实验室及全省唯一的人类精子库于一体，是国内知名的男科临床技术服务和科学研究基地之一，拥有国家及广东省人类辅助生殖技术专家3名，高级职称技术人员9名，硕博及以上学历人员9名。开展精液分析相关的临床服务和技术研究近40年，具备较扎实的男性生殖医学工作基础和条件。

医院一直非常重视精液常规分析及精子形态学分析，坚持按WHO手册的方法进行精液分析，并建立了一套较完善的内部质量控制体系，包括建立了精液分析的标准程序、质控品的制作及标准、实验室人员培训方案、实验室及仪器耗材质控方案、精液分析的内部质量控制方法等，精液分析技术非常稳定。

从2009年开始逐步建立了区域性精液分析外部质量控制体系，参与实验室的数量逐年增长，截至2022年，省内外182家精子库和生殖医学中心慕名自愿加入我院组织的精液分析外部质量控制体系，遍布全国各省、直辖市。

我院的精液分析外部质量控制规模为全国最大，质控实践不断规范实施；精液分析外部质量控制在全国生殖男科领域及实验室质量管理方面有较大影响力，受到同行专家的肯定和好评。
