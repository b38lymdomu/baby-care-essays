# 人民医院召开职工代表大会，推出"十四五"规划，明确“双十”目标。

> 更新时间：2026-09-16 (UTC+8)

3月13日，医院第十届二次职工代表大会在门诊五楼学术报告厅顺利举行。本次大会共有386代表参加会议，大会提出了“十四五”发展规划，明确了医院"十四五"发展十大目标和医院2021年十大目标。市委常委、宣传部长陈小华、副市长龚杭娟、市卫健局局长楼杰华、市卫健局副局长吴朝红等领导莅临参会。

**2020年八大成就**

**顶呱呱**

大会听取了大会听取并审议了吕忠院长所做《医院工作报告》。报告总结了东阳市人民医院2020年所取得的八大成就：

（一）全力以赴抗击新冠肺炎疫情。面对突如其来的新冠肺炎疫情，全院动员，迎难而上，6天建成东阳市新冠肺炎第二定点医院，平稳闯过首例患者出现早、确诊病人突然增多、医院内部安全受到严重威胁等多个关口，率先在浙中西部疫情最严重的地区完成19例新冠病人清零。率先开发应用发热病人追踪管理系统，迅速成立4个院内防控专家小组，严密实施“一根弦两防线三措施”，确保常态化防控不留缝，为全市人民构筑起了一道坚实的健康“长城”，为全市夺取疫情防控阶段性胜利作出了重要贡献。

（二）扎实有力推动医疗技术发展急救技术全面提高。大力发展救心、救脑、救命技术，“胸痛中心”“高级脑卒中中心”“心衰中心”通过国家级中心认证，急诊脑卒中溶栓、急诊PCI的主要指标处于全国领先水平。“五项短板技术”得到加强，辅助生殖技术稳步推进，试管婴儿生产突破100例。25个术种排名进入全省前20，全院综合CMI居全省第17名，RW≥2.0疑难病例数3493例，全省第19名；三四级手术7685台（占比30.32%），全省第18名；日间手术病例数4217例，全省第12名。

（三）坚定不移提升医疗质量水平。全力推进制度3.0，395个结构式制度、109个标准化作业书和56个医院服务标准，为质量管理提供了现代化的有效工具。两大肺炎防控、麻醉质控体系、抗栓药物使用等24个质量改进专案得到了有效推进，医疗质量与安全运行管理得到持续改善。

（四）持之以恒提升学科建设和科教水平。学科建设保持稳中有进态势。产科建立内部运行机制，市场占有率稳中有升；呼吸内科调整内部资源，重点技术发展有序推进；心脏外科和心内科组资源重组，融合发展势头良好；神经外科、泌尿外科重视科室质量管理，质量各项指标明显改善；重症医学科以优秀评级通过县级医学龙头学科验收。教学举措有力有效。全年发表论文120余篇，其中SCI论文56篇、中华级杂志19篇。专利授权109项。

（五）多措并举完善医疗服务

“最多跑一次”改革更加深入。成为金华市首家实现医保脱卡移动支付的医院。上线手机“慢病续方”功能，药品快递到家全程“零次跑”。持续完善门诊一站式服务中心的功能，门诊智慧挂号率达85.18%，门诊智慧交费率达84.2%，门诊病人交费等候时间缩短到4.54分，老百姓就医获得感不断提升。依托大数据平台创新智慧报表系统助力智慧运行和精细化管理，移动挂号、自助入院、体检健康管理系统等功能陆续上线。牵头开发智能亮灯系统和智能发药系统，配合相关部门开发中药云药房。

（六）群策群力做好县域医共体

公卫管理迈出新步伐，成立了医院公共卫生科，公共卫生管理能力得到强化。大力推进信息化的慢病管理体系，“两慢病”发现率、治疗率、控制率得到明显提高。健康档案管理走深走实，积极推进居民健康档案的核查和清理工作，规范档案建立和注销机制，建立档案动态更新制度，档案复核率达85.03%。积极推动2020年“优质服务基层行”活动，南马镇中心卫生院受到国家卫生健康委通报表扬。

（七）蹄疾步稳推进大部制融合

以“大部制”为手段推进三院区集团化融合取得新进展。骨科、肛肠外科、麻醉团队率先搭建了“一体化诊疗”机制，门诊量、手术量有了新提升。组织三院区中层干部管理培训，开展首批以院区及新提拔临床科室主任为核心的卓越管理工作坊，科室一线管理能力进一步加强。信息科实现一部制，三院区信息一体化机制得到有力保障。以“三甲”标准和要求，同步开展质量与安全现场追踪，扎实推进巍山、义乌两院区“二甲”综合医院评审准备工作。

（八）从严从实加强医院自身建设

党委领导下院长负责制得到强化，顺利完成党支部选举，党支部由33个调整为62个，基层党组织建设不断加强。内部审计列入常态化工作推动规范管理。全院全员创建“无交通违章医院”“无违章月”“无违章科室”成果显现。全面推进清廉医院建设，荣获金华市首批清廉医院示范单位称号。

社会公益日活动深入开展，精细化管理培训班有序组织，互联网医院架构形成。人事招聘、后勤保障、基本建设、宣传等工作取得新进步。全院性医院文化大讨论形成新愿景，医院目标定位更加明确，发展思路更加清晰。

**“十四五”规划十大目标**

**高大上**

吕忠院长还在报告中，对医院《“十四五”发展规划（草案）》作了简要介绍。《规划》提出了医院今后五年发展的总体目标和五大块35项具体指标，并提出了实现"十四五"目标的十大举措。

"十四五"规划总体目标是：

面对新机遇新挑战，医院要深入贯彻新时代党的卫生与健康工作方针，深刻理解国家公立医院绩效考核体系下的公立医院运行目标，准确把握新一轮等级医院评审高标准严要求，有效应对医保政策特别是DRG\DIP支付对医院运行方式带来的深刻变化，锚定“高质量浙中医疗集团、现代化三级甲等综合医院全国县域标杆、双一流大学附属医院”愿景，培育和弘扬“担当、较真、强壮、韧性、自信”文化特质，沉心静气，奋发作为，乘势而上推动“三甲”医院内涵建设更加丰富、浙中区域医疗中心重要组成部分地位更加坚实、市域（东阳）医学中心作用更加凸显，实现更高水平、更有质量、更具效率的发展，切实保障人民健康权益，为健康中国建设贡献力量，为健康东阳建设发挥主力军作用。

"十四五"规划十大目标是：

1.更好发挥治理制度优势。

2.推进内部运行机制改革。

3. 与国家乡村振兴战略相衔接，做好医共体，为健康东阳建设作出更大贡献。

4.建成有质量有影响力的浙中医疗集团。

5.业务规模保持合理稳定增长。

6.经济运行稳健高效，职工收入稳步增长。

7.打造高效能智慧型医院。

8.坚持“外引内育”，人才队伍建设跨上新台阶。

9.专业技术能力和学科建设达到新水平。

10.教学和科研迈出新步子。

**2021年十大目标**

**接地气**

吕忠院长还在《医院工作报告》中阐述了2021年医院工作思路，提出在新的一年，医院要抓好十大重点工作：

（一）以党建融入医院各项工作为统领，加强思想政治建设，提升干部职工的政治素质；

（二）以“三大指标”为驱动，高质量完成年度工作任务；

（三）以推升“三外”服务增量为抓手，培育医院优势服务新动能；

（四）以主动适应医保支付改革为着力点，逐步建立和完善以DRG为基础的绩效评价机制，确保医院稳健运营；

（五）以对接国家医疗中心为制高点，深化实施“六个一”战略，推动医疗技术实现新提升；

（六）以打好质量管理“五大攻坚战”为主线，争创省政府质量奖；

（七）以院外引进和院内培育PI为突破口，推动学科建设和医学科研提质破局；

（八）以组建浙中医疗集团为契机，加快推进优质医疗资源扩容覆盖；

（九）以“三个延伸”为切入点，夯实医共体整合医疗服务，提升病员群众健康获得感；

（十）以“国内一流”为目标，运用现代化、信息化思维，建设好未来手术中心；

**巍山院区**

**励精图治，加速前行**

副院长、巍山院区院长张忠延在大会上作了《巍山院区工作报告》，回顾了2020年巍山院区工作成绩。过去的一年，医院不断完善医疗管理体系，推进专科建设，提升专案管理质量，优化急救流程，强化急救能力，脑梗死溶栓时间DNT中位数28分钟居金华市第一。此外，医院也重视员工综合能力提升，扎实开展医共体工作、党建工作，推进优质服务2.0，构建和谐的医患关系。

面对新冠疫情的突袭，巍山院区积极组织力量，做好疫情防控同时，坚持“1个中心、2大特色、3+2重点专科”发展战略，以病人安全为目标，扎实推进医疗发展。

他在报告中提出了新一年的七大工作重点：

1.加强党、团、工会工作，弘扬“五大文化”，提升员工人文素养，增强员工凝聚力；

2.做好常态化新冠疫情防控，在医保管理制度下，优化经营，推进业务的提升；

3.以顺利通过等级医院复评为目标，强化闭环管理，推进持续质量管理；

4.以“差异化发展”为方向，以“科有特色、人有专长”为目标，推进技术和学科建设，提升行业竞争力；

5.以“共享，共赢”为基础，组合上下资源，推进医共体建设和医院集团化发展；

6.以“医患无忧”为愿景，做好“最多跑一次”项目，完善医院优质服务体系；

7.以建“花园中的医院”为目标，提升后勤保障能力。

**义乌院区**

**五年成绩斐然,****推进高质量发展**

党委副书记、副院长、义乌院区院长赵永明在大会上作了《义乌院区工作报告》，回顾了义乌院区建院5年来所取得的成绩，并提出了2021年医院八大工作思路。

五年来，义乌院区传承和发扬了本部医院文化，借力本部集团化办医、大部制体系的有力推动，学科门类日渐齐全、人才结构日益完善，服务品质、学科建设、后勤保障等各方面实现同质化发展，为体现综合性医院实力打下坚实基础；这五年，义乌院区在医疗资源丰富带来的激烈竞争下，在新冠肺炎疫情的猛烈冲击下，医院各项业务指标不降反增，医院良好的口碑初步形成，具备了良性发展的基础，激发了义乌卫生事业市场活力，也提升了东阳本部在浙中地区的口碑。

2.扶持特色学科、差异化学科，打造成为品牌学科；

3.充分挖掘集团化办医资源发展义乌院区，提升义乌院区各级管理层面的能力；

4.继续推动服务改进，打响服务品牌；

5.适应物价、医保的各项政策调整和管控力度加大的现状，提升应对能力；

6.建立基础网络体系，推进互联网医院建设；

7.推进员工生态环境建设；

8.提绩增效，努力推进医院高质量发展。
