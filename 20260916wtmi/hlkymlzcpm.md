# 喜讯！丽水市人民医院东城院区三期项目获市发改委批复

> 更新时间：2026-09-16 (UTC+8)

👆点击丽水市人民医院星标我们
丽水市人民医院东城院区建设又有了新进展，医疗科教综合楼（东城院区三期）项目可行性研究报告近日获市发改委批复。
项目位于丽水市人民医院东城院区东侧，总用地面积约50600平方米，总建筑面积约 61811平方米，其中地上建筑面积约32779平方米，地下建筑面积约29032平方米。主要建设内容包括医疗连廊工程、和平路（丽阳街-寿元路）道路工程、香樟公园、医疗科教综合楼主体工程等4个子工程。项目估算总投资约68456万元。 
<<  滑动查看下一张图片  >>

根据丽水市人民医院东城院区总体规划，医疗科教综合楼是实现医院医疗、科研、教学和现代管理多轮驱动、协同发展的重要功能分区。项目的实施为持续建设高质量、高水平和创新型的全国有影响力的区域医疗中心、医学教育及培训中心、科学研究及创新成果转化中心夯实了基础。
下一步，市人民医院将加快推进建筑设计方案优化、初步设计和施工图的编制和相关报批工作。各子工程计划于今年下半年陆续开工建设。
